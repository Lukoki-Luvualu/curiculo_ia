# Gerador de Currículo com IA

Aplicação web desenvolvida em Python utilizando Streamlit e OpenAI.

## Funcionalidades
- Geração automática de currículos
- Otimização para ATS
- Download em PDF
- Interface simples e rápida

## Tecnologias
- Python
- Streamlit
- OpenAI
- WeasyPrint

## Acesso
Aplicação online via Streamlit Cloud.
